# Backend

## Third-party data

### ESCO skills taxonomy (`app/data/skills_index.json`)

This service uses the [ESCO classification](http://ec.europa.eu/esco) of the European Commission.

Source: ESCO v1.2.1, European Skills, Competences, Qualifications and Occupations, © European Union. Used under [Commission Decision 2011/833/EU](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32011D0833) on the reuse of Commission documents — free for any purpose, including commercial use, with attribution.

`skills_index.json` is a **modified/adapted version** of the original ESCO dataset, generated by `scripts/ingest_esco.py`: filtered to `released`-status, English-labeled skill/knowledge concepts only, and restructured into a flat `{normalized_label: {label, uri, alt_labels, source}}` lookup. It is not the original ESCO distribution.

To regenerate: download the full ESCO classification XML export from https://esco.ec.europa.eu/en/use-esco/download (requires submitting an email address to receive the download link — no way to automate this step) and run:

```
python scripts/ingest_esco.py <path-to-esco-vX.Y.Z.xml>
```

### O*NET Software Skills (merged into the same `app/data/skills_index.json`)

This product was developed by referencing the O*NET 30.3 Database by the U.S. Department of Labor, Employment and Training Administration (USDOL/ETA). Used under the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/). O\*NET® is a trademark of USDOL/ETA — used here as an adjective, not as a noun or verb, per O\*NET's trademark usage rules.

Source: O*NET 30.3, "Software Skills" file (https://www.onetcenter.org/database.html) — downloads directly, no registration required. Chosen over O*NET's "Essential Skills" file, which covers ~35 broad competency dimensions ("Reading Comprehension", "Active Listening") with numeric ratings, not skill *terms*. "Software Skills" lists real, specific tool/software names — exactly the brand/tool-name coverage ESCO's vendor-neutral vocabulary doesn't have (confirmed directly: "Figma" isn't in ESCO; it is in O*NET's Software Skills data).

Entries are merged into the same index `scripts/ingest_onet.py` produces from `ingest_esco.py`'s output — a modified/adapted combination of both sources, tagged per-entry with `"source": "esco"` or `"source": "onet"`. To regenerate the O*NET half: download `software_skills.csv` from https://www.onetcenter.org/dl_files/database/db_30_3_csv/software_skills.csv and run:

```
python scripts/ingest_onet.py <path-to-software_skills.csv>
```

Run `ingest_esco.py` first (it's the base the O*NET script merges into).
